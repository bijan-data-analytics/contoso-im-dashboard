# Contoso Data Analytics Dashboard

## Overview
This project demonstrates a data analytics and information management dashboard built using fictional Contoso data.

## Objective
The goal is to transform raw data into actionable insights to support decision-making.

## Tools Used
- Power BI
- Excel
- Data Modeling
- DAX

## Dashboard Pages
- Executive Overview
- Geographic Analysis
- Program Performance

## Key Metrics
- Total Activities
- Total Beneficiaries
- Total Services
- Achievement %
- Performance Status

## Files
- PBIX dashboard file
- Excel dataset
- Dashboard screenshots
